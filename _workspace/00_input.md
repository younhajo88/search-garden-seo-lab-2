# Input

## Request
사용자가 SEO 실험용 Next.js 프로젝트를 실제로 진행하자고 요청했다.

## Constraints
- 구현 전 `topic-discovery`를 먼저 실행한다.
- 정확히 세 개의 실용 도구형 주제 후보를 조사하고 점수화한다.
- 사용자가 후보 하나를 명시적으로 승인하기 전에는 Next.js 애플리케이션을 스캐폴딩하거나 구현하지 않는다.
- 무료로 접근 가능한 웹 검색 결과, 공식 문서, 경쟁 페이지 신호만 사용한다.
- 초기 릴리스 범위는 실용 도구 1개와 한국어 가이드 5개다.
- 한국어 우선으로 설계하되, 영어 확장 구조를 나중에 붙일 수 있어야 한다.
